# Lynbro SMTP Mailer

Send WordPress email through your own SMTP server, with an email log, resend, a backup connection and failure alerts. All free, no upsells.

- WordPress.org: https://wordpress.org/plugins/lynbro-smtp-mailer/
- Documentation: https://plugins.lynbro.dk/lynbro-smtp-mailer
- Support and bug reports: the [WordPress.org support forum](https://wordpress.org/support/plugin/lynbro-smtp-mailer/), or open an issue here.

The code in this repository is the code released on WordPress.org (current: 1.1.6). GPL-2.0-or-later. Made by [LynBro ApS](https://lynbro.dk).
